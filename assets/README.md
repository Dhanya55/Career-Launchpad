# Assets

This directory is intended for the visual materials used by the site.

## Suggested asset categories

```text
assets/
├── images/
├── icons/
├── logos/
└── background/
```

## Use cases

- Store hero images, team photography, and program screenshots
- Keep brand logo files in a consistent place
- Avoid scattering image files across the repo root

## Migration note

The current project still has files in the original `Career Launchpad/` folder. As cleanup continues, image and media files should be moved here for consistency.
